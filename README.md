# Запас — CRM для инвентаризации

Интерактивный прототип CRM для склада, кухни и кейтеринга. Сделан для студенческого конкурса UX/UI «Дизайн CRM для инвентаризации».

## Идея

Система построена вокруг одного действия: вовремя пополнить запас. Она сама показывает, чего мало и что скоро испортится, предлагает количество к заказу и делит заказ по поставщикам. При приёмке остатки обновляются автоматически, а аналитика показывает, где теряются деньги на списаниях.

## Экраны

1. Обзор
2. Инвентарь
3. Карточка товара
4. Новая закупка
5. Заказ: приёмка поставки
6. Закупки
7. Аналитика и отчёты

## Сценарий «Пополнение запаса»

Найти позиции с низким остатком → собрать из них закупку → отправить заказ поставщику → принять поставку, остатки обновятся.

## Запуск

Откройте `index.html` в браузере. Сборка и сервер не нужны. Данные демонстрационные и хранятся в `localStorage` браузера; кнопка «Сбросить демо-данные» возвращает их к началу.

## Файлы

- `index.html` — разметка
- `styles.css` — стили
- `app.js` — данные и логика
